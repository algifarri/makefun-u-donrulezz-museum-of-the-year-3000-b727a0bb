Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun: write one line — the museum label a museum in the year 3000 puts beside an ordinary object from today — in at most 200 characters.

## The entry

> Remote Control, c. 2023. Scepter of the household throne. Its bearer commanded light, sound, and silence — yet spent every evening searching for it between the cushions.

169 characters. A year-3000 curator misreads the remote as royal regalia: a scepter that commands light, sound, and silence — whose all-powerful bearer still loses it down the side of the sofa every single night.

## How it works

`main.py` (Python 3, standard library only) writes that single line to `/output/entry.txt`. Deterministic: the same bytes on every run. Verified locally: the output is exactly 169 characters, inside the 1–200 character gate.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
